IMPORTANT:
The website uses free Unsplash-hosted photos by URL. If you want all images stored locally
inside GitHub, download/replace them later in an images folder and change the <img src=""> URLs.

GITHUB UPLOAD:
1. Open your GitHub repository for excellencechimneyservice.shop.
2. Upload index.html, style.css, robots.txt and sitemap.xml.
3. Commit changes.
4. If GitHub Pages is already connected to your domain, wait a few minutes for the update.
5. Open https://excellencechimneyservice.shop/ in mobile Chrome and refresh.

If your GitHub repository uses a different branch, keep the same branch that is currently connected
to the custom domain.

DNS:
Do not change DNS just for this design if the existing website is already opening correctly.
