## Upload to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the complete `images` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** branch and **/(root)** folder, then Save.
6. Wait for the GitHub Pages deployment.
7. Your website should open from the Pages URL.

### Important
Keep the folder/file names exactly the same:
`index.html`
`style.css`
`script.js`
`images/service-1.png` through `images/service-6.png`

For your custom domain, add `CNAME` later if your DNS is configured for GitHub Pages.
