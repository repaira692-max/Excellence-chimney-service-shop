## Upload to GitHub
1. Create/open your GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `config.js` and the `assets` folder.
3. If using GitHub Pages, enable Pages from Settings → Pages → Deploy from branch.
4. Keep your custom domain DNS pointed to GitHub Pages if the current domain is already connected.

## Booking behavior
Clicking a service-area PIN opens WhatsApp with a pre-filled message containing the city and PIN. The customer can add their name, mobile number and required service.

## Data note
Delhi and Gurugram PIN data was checked against current government/district sources during preparation. Other city lists are included as service-area PINs and should be reviewed against your actual operational coverage before advertising “all PIN codes”.
