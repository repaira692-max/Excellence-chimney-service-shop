## Upload to GitHub
1. Create a new GitHub repository, e.g. `excellence-chimney-service`.
2. Upload `index.html`, `style.css`, `CNAME`, and the `assets` folder.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. In **Custom domain**, enter `excellencechimneyservice.shop` and Save.
6. At your domain DNS provider, point the domain to GitHub Pages according to GitHub's current DNS instructions.
7. Turn on **Enforce HTTPS** after DNS is active.
